# Educational Spectrum Sensing System for FM Broadcasting
## Complete Design Document for RTL-SDR Based Laboratory Platform

---

## A. Executive Summary

This design proposes a **receive-only, educational spectrum monitoring system** for the 88–108 MHz FM broadcast band using commodity RTL-SDR hardware. The system targets university laboratory environments where students progress from simulation through recorded data to live RF capture. Key technical constraints include managing the RTL-SDR's 8-bit ADC dynamic range (~48 dB), DC spike removal, IQ imbalance compensation, and careful gain staging to avoid intermodulation.

The architecture centers on a Python/GNU Radio software stack with modular signal processing blocks: calibration → DC/null rejection → channelized filtering → Welch PSD estimation → energy detection → occupancy visualization. Performance targets include ±50 kHz frequency accuracy, >20 dB SNR for local FM stations, and real-time spectrum update rates >10 Hz on standard PC hardware.

**Total hardware cost: <$50 USD** (RTL-SDR v3 + dipole antenna kit). The design explicitly excludes transmission capability and assumes indoor laboratory use with local broadcast signals.

**Tradeoff Analysis**: The optional bandpass filter adds $2–5 cost but provides:
- Image frequency rejection (signals at 78–88 MHz aliasing into passband)
- Out-of-band interference suppression (cellular, pager signals)
- Reduced ADC overload risk from strong nearby transmitters

| Stage | Component | Parameters |
|:---|:---|:---|

**Critical RTL-SDR Limitations & Mitigations**:

| Limitation | Impact | Mitigation Strategy |
|:---|:---|:---|
| **8-bit ADC** | ~48 dB theoretical dynamic range; quantization noise | Manual gain optimization; avoid AGC on weak signals; accept reduced dynamic range |
| **Zero-IF DC spike** | Strong artifact at center frequency | Frequency offset tuning (tune 500 kHz away from signal of interest); DC cancellation block |
| **IQ imbalance** | Image signals at negative frequencies | Calibration with known CW signal; software IQ correction |
| **Phase noise** | ~−80 dBc/Hz at 10 kHz offset | Acceptable for FM broadcast; use external reference for precision |
| **Sample rate quantization** | Only specific rates stable (e.g., 2.4, 1.92, 1.024 Msps) | Use 2.4 Msps with decimation |
| **Gain step resolution** | ~1 dB steps, not continuous | Fine-tune near compression point |
| **Aliasing** | Inadequate front-end filtering | External BPF or accept limited performance |

## E. Signal-Processing Pipeline (Detailed)

### E.1 Capture Stage

**Parameters**:
- Sample rate: 2.4 Msps (complex baseband)
- Center frequency: 98.0 MHz (band center)
- Gain mode: Manual (start with 30 dB, adjust for −20 to −10 dBFS peak)
- Frequency correction: Apply PPM offset (typically 0–50 ppm for RTL-SDR)

**Concrete Implementation (Python pseudocode)**:
```python
from rtlsdr import RtlSdr

sdr = RtlSdr()
sdr.center_freq = 98e6      # 98 MHz center
sdr.sample_rate = 2.4e6     # 2.4 Msps
sdr.gain = 30               # Manual gain, dB
sdr.freq_correction = 20    # PPM correction (calibrate against known station)
samples = sdr.read_samples(256*1024)  # 0.1 second capture
```

### E.2 Calibration Stage

**E.2.1 DC Spike Cancellation**
The RTL-SDR zero-IF architecture produces a strong DC component at the tuner center frequency. Two mitigation approaches:

1. **Frequency Offset Method (Preferred)**: Tune 500 kHz away from band center, digitally shift to baseband
   - Tune to 97.5 MHz or 98.5 MHz
   - Complex multiply by exp(−j2πΔft) to shift spectrum

2. **Digital DC Block**: IIR notch filter at 0 Hz
   - Transfer function: H(z) = (1−z⁻¹)/(1−αz⁻¹), α ≈ 0.99
   - Attenuates DC but creates null at center (acceptable if no signal there)

**E.2.2 IQ Imbalance Correction**
Estimate and compensate gain/phase imbalance using statistical methods:

```python
# IQ imbalance estimation
I = np.real(samples)
Q = np.imag(samples)
gain_imbalance = np.std(Q) / np.std(I)
phase_error = np.mean(I * Q) / (np.std(I) * np.std(Q))

# Correction
Q_corrected = (Q - phase_error * I) / gain_imbalance
samples_cal = I + 1j * Q_corrected
```

**E.2.3 Gain Staging Strategy**
Target: Peak signal at −10 to −6 dBFS (leaves 6–10 dB headroom for fades, avoids clipping).

- Start with 20 dB LNA gain
- Capture 10k samples, measure peak magnitude
- If peak < −30 dBFS: increase gain by 10 dB steps
- If peak > −3 dBFS: decrease gain (risk of intermodulation)
- **Never exceed 40 dB gain in high-RF environments** (urban/campus)

### E.3 Filtering Stage

**Anti-aliasing & Channel Selection**:
- Input sample rate: 2.4 Msps (bandwidth 2.4 MHz)
- FM channel bandwidth: ~200 kHz (including guard bands)
- Decimation factor: 12 → output rate 200 ksps per channel

**Polyphase Channelizer** (efficient implementation):
```python
# Design prototype lowpass filter (FIR, 200 kHz cutoff)
taps = scipy.signal.firwin(240, 0.083, window='hamming')  # 240 taps, 2.4M→200k

# Polyphase decomposition
channels = 12
poly_taps = taps.reshape(channels, -1)

# Channel selection via complex exponential mixing
channel_centers = np.arange(88, 108, 0.2)  # 200 kHz grid
```

### E.4 FFT / PSD Computation

**Welch Method Parameters**:
- FFT size: 1024 points → frequency resolution 2.34 kHz (at 2.4 Msps)
- Window: Hamming (good compromise between mainlobe width and sidelobe attenuation)
- Overlap: 50%
- Averaging: 16–32 periodograms for stable estimate

**Power Calculation**:
```python
# PSD in dBm/Hz (assuming 50Ω impedance, RTL-SDR full scale ~0 dBm)
def compute_psd(samples, sample_rate):
    nfft = 1024
    f, Pxx = scipy.signal.welch(samples, fs=sample_rate, 
                                window='hamming', nperseg=nfft,
                                noverlap=nfft//2, scaling='density')
    # Convert to dBm (assuming 0 dBFS = 0 dBm for simplicity; calibrate with source)
    psd_dbm = 10 * np.log10(Pxx * 1000)  # W to mW
    return f, psd_dbm
```

**Calibration Note**: RTL-SDR absolute power calibration requires a known reference source. For educational purposes, use relative dB scale normalized to noise floor, or calibrate against a signal generator at −50 dBm.

### E.5 Occupancy Detection

**Energy Detection Algorithm**:
1. Compute noise floor: Median of PSD over time (robust to outliers)
2. Set detection threshold: Noise floor + 10 dB (empirical; adjustable)
3. Binary mask: PSD > threshold → channel occupied
4. Hysteresis: 3 dB gap between detect/on and release/off to prevent chatter

**FM Channel Grid Alignment**:
- Standard FM spacing: 200 kHz (US/Europe) or 100 kHz (some regions)
- Channel bandwidth detection: Find −20 dB points around peak
- Center frequency estimation: Centroid of occupied bins

```python
def detect_occupancy(psd_dbm, freq_axis, threshold_db):
    # Threshold based on noise floor estimate
    noise_floor = np.median(psd_dbm)
    threshold = noise_floor + threshold_db
    
    occupied = psd_dbm > threshold
    
    # Find contiguous regions
    from scipy.ndimage import label
    labeled, n_features = label(occupied)
    
    channels = []
    for i in range(1, n_features + 1):
        mask = labeled == i
        if np.sum(mask) > 5:  # Minimum 5 bins (~12 kHz)
            center = np.average(freq_axis[mask], weights=psd_dbm[mask])
            bw = freq_axis[mask][-1] - freq_axis[mask][0]
            channels.append({'center': center, 'bandwidth': bw, 'peak_db': np.max(psd_dbm[mask])})
    
    return channels
```

## H. Validation Plan

### H.1 Test Equipment Required

| Equipment | Purpose | Alternative |
|:---|:---|:---|
| RF signal generator | Sensitivity, linearity, frequency accuracy | Commercial FM transmitter (known frequency/power) |
| Power meter/Spectrum analyzer | Absolute power calibration | Calibrated RTL-SDR comparison |

### H.2 Validation Procedures

**H.2.1 Sensitivity Test**
1. Connect signal generator to RTL-SDR via 40 dB attenuator (protects front end)
2. Generate FM signal at 98 MHz, 75 kHz deviation, 1 kHz tone
3. Adjust generator output for 20 dB SNR in 200 kHz bandwidth
4. Record minimum detectable signal level
   - **Target**: ≤−80 dBm for 20 dB SNR
   - **Acceptance**: ≤−75 dBm

**H.2.2 Dynamic Range Test**
1. Two-tone test: Generate strong signal at 98 MHz (−30 dBm) and weak signal at 98.2 MHz (−70 dBm)
2. Measure intermodulation products (2f1−f2, 2f2−f1)
3. Adjust gain to minimize IM3 while maintaining weak signal visibility
   - **Target**: IM3 < −40 dBc
   - **Acceptance**: IM3 < −30 dBc

**H.2.3 Frequency Accuracy**
1. Tune to known station with published exact frequency (e.g., 88.5 MHz NPR affiliate)
2. Measure received center frequency via FFT centroid
3. Calculate error: (measured − actual) / actual × 1e6
   - **Target**: < ±5 ppm (±500 Hz at 100 MHz) with TCXO
   - **Acceptance**: < ±50 ppm (±5 kHz)

**H.2.4 Occupancy Detection Accuracy**
1. Collect 24-hour ground truth: Manual logging of station activity or reference receiver
2. Run automated detection on same dataset
3. Compute metrics:
   - True Positive Rate (TPR) = Detected active / Actually active
   - False Positive Rate (FPR) = Detected inactive / Actually inactive
   - **Target**: TPR > 90%, FPR < 5%

**H.2.5 Repeatability**
1. Five identical setups (same hardware batch, same software version)
2. Same location, same time, same antenna
3. Measure PSD of strong local station; coefficient of variation < 10%

| Risk | Likelihood | Impact | Mitigation |
|:---|:---|:---|:---|

| USB buffer overruns (dropouts) | Low | Medium – data loss | Reduce sample rate; use USB 3.0 port; close background apps |
| PPM drift causes frequency error | Medium | Medium – misidentification | TCXO-based RTL-SDR; periodic recalibration |

| Python/GNU Radio installation issues | Medium | Medium – lab delays | Pre-configured VM image; Docker container; lab PCs pre-installed |
| Weak signal environment (rural campus) | Medium | High – no signals to detect | Provide recorded dataset fallback; FM transmitter for testing |

## K. Final Recommendation

**Proceed with the RTL-SDR Blog v3-based design** as specified. This architecture satisfies all constraints:

✅ **Receive-only**: No transmission capability, fully compliant  
✅ **Educational**: Three-stage progression from simulation to hardware  
✅ **Low-cost**: ~$30 hardware, free software  
✅ **Technically sound**: Addresses all RTL-SDR limitations (8-bit ADC, DC spike, IQ imbalance, gain staging)  
✅ **Reproducible**: Standard PC, well-documented software stack  
✅ **Validated**: Quantifiable performance targets and test procedures included  
✅ **Extensible**: Modular GNU Radio blocks support future enhancements (direction finding, multi-SDR correlation, other bands via upconverter)

**Critical Success Factors**:
1. **Mandatory external bandpass filter** for labs in high-RF environments (urban campuses, near broadcast transmitters)
2. **Manual gain mode** – disable RTL-SDR AGC for consistent measurements
3. **Frequency offset strategy** – never place signals of interest at exact center frequency
4. **Pre-lab software validation** – provide VM/container to eliminate installation barriers

**Future Extensions** (maintaining receive-only constraint):
- Multi-SDR phase coherence for direction finding (KerberosSDR or synchronized units)
- ISM band monitoring (433 MHz, 915 MHz) with appropriate antennas
- ADS-B aircraft monitoring (1090 MHz) as complementary exercise
- Satellite reception (NOAA APT, Meteor M2) with L-band downconverter

This design provides a robust foundation for RF education while maintaining strict adherence to regulatory constraints and pedagogical best practices.
