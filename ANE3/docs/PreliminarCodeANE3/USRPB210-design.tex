\item{Outdoor/Rooftop Monitoring}
Outdoor installations require additional considerations for weather resistance and safety:

\begin{itemize}
	\item \textit{Non-penetrating roof mounts} while providing secure mounting
	\item \textit{Mast mounting (1.25''--2'' diameter)} -- Standard mast sizes for antenna installation
	\item \textit{Weatherproof antenna enclosures} protecting sensitive RF components from environmental exposure
	\item \textit{Grounding and lightning protection} 
	\item \textit{Quality low-loss cables (LMR-400)} -- Minimize signal degradation over longer cable runs
\end{itemize}

\textit{Testing \& Calibration}

\begin{itemize} 
\item \textit{Antenna Performance Verification}

Proper system characterization requires several key measurements:

\begin{description}
	\item[VSWR Measurement:] Use NanoVNA or similar vector network analyzer to verify antenna impedance matching
	\item[Gain Pattern:] Compare received signal levels against known reference signals to validate antenna gain
	\item[Frequency Response:] Perform frequency sweep tests with USRP to characterize system response across bands
	\item[Noise Floor:] Establish baseline noise measurements for sensitivity analysis
\end{description}

\item \textit{Software Tools}

The following software tools are recommended for system testing and operation:

\begin{description}
	\item[GNU Radio:] Spectrum analyzer flowgraph development and signal processing
	\item[GQRX:] Real-time spectrum visualization and monitoring
	\item[URH (Universal Radio Hacker):] Advanced signal analysis and protocol decoding
\end{description}
\end{itemize}
\end{enumerate}

\emph{Compute and pipeline}

\begin{enumerate}[leftmargin=*,label={\arabic*.}]
	\item \gc{ML Pipeline}: PyTorch anomaly detection. Use cuFFT/cuSignal with pinned memory and zero-copy buffers where possible.
	\item Prefer 8-bit IQ for streaming/storage unless dynamic range needs dictate 12/16-bit.
		\item Ensure UHD decimation in the FPGA and keep host sample rates modest (e.g., 2–10 Msps per channel) for sustained real-time operation.
	\item \gc{UI}: Flask web dashboard with gr-specest waterfalls
\end{enumerate}
