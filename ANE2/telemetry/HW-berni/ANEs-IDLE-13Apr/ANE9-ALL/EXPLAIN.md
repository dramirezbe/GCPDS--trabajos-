Carpeta donde está el nodo ANE9, con el software completamente instalado y funcional, usando LTE(ppp0) para manejo de internet (Está en Funza, cámara de servidores).

ALL_PERIPH_* = Con PCB(LTE, GPS, Mux) y HackRF conectadas.

*_MID_PETITION = Haciendo petición desde el servidor media RBW 3k, sample_rate 20MHZ.

config-firmware.sh = configuración del archivo /boot/firmware.conf (Importante para saber si por software se puede reducir el consumo de energía o no)
config-eeprom.sh = configuración del archivo /boot/eeprom.conf (Importante para saber si por software se puede reducir el consumo de energía o no)
